## 交付前检查

- [ ] 只有一个点子、一次反转
- [ ] 最后 5 秒是画面能说清的
- [ ] 没有解释设定（机制只通过后果呈现）
- [ ] 推演严格，没有为了效果破坏逻辑
- [ ] 结尾给的是更大的问题，不是答案
- [ ] 奇观低成本可执行
- [ ] 时长与结构规格匹配（3 拍 / C5 / 8 拍）
- [ ] 视觉母题出现三次并变义
