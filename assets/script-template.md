# 科幻短片剧本格式模板

> 用法：复制本文件，按格式填。**页数 ≈ 分钟数**（1 页 ≈ 1 分钟）。
> 交付时必须包含：① 标题页信息 ② 拍子表 ③ 剧本正文。

---

## 一、标题页

```
片名：________
时长：__ 分钟        页数：__ 页
一句话（logline）：如果把 ______ 推到极限，那么 ______。
类型标签：冷科幻 / 暖科幻 / 诡科幻        结构模板：3 拍 / 5 拍 / 8 拍
主要场景数：__        主要人物数：__
科幻构思（一句话）：________________
最后 10 秒的反转：________________
```

## 三、剧本正文格式

### 场次头（三要素：场景 / 时间 / 内外）
```
1. 内景  整理间  日
```
或
```
3. 外景  天台  夜
```
> 短片场景尽量少。5 分钟片建议 **≤3 个场景**。

### 动作描述（现在时，只写镜头能拍到的）
```
　　阿哲戴上手套，把一叠硬盘按日期码放整齐。第三块盘上贴着标签：
　　"父亲 / 最后三个月"。他把它推到一边，先拿最上面那块。
```
**规则**：
- 只写**能看见、能听见**的东西。不写心理活动。
- 不写镜头术语（除非叙事必需）。
- 每段不超过 4 行。短片要留白。

### 人物首次出场（名字 + 一个动作特征）
```
　　客户是个五十多岁的女人，进门先用手帕擦了擦椅子才坐下。
```
> 名字尽量普通、易记。科幻短片**不要给太多人名**（参考星新一：无名、无地、无时代反而更耐久）。

### 对白
```
　　　　　　　　　　　阿哲
　　　　　整理需要七天。这七天里，请不要看他生前的照片。

　　　　　　　　　　　客户
　　　　　（点头）七天。

　　　　　　　　　　　阿哲
　　　　　还有一条。不要问我，他会不会认得你。
```
**规则**：
- **不解释设定**。机制只通过后果呈现。
- **说人话**。不说"量子通信阵列出现相位偏移"，说"又断了"。
- 想说设定时，让一个**不懂的人**问，让一个**不耐烦的人**答一半。
- 对白能删就删。**先把对白全删一遍，看故事还成不成立**；不成立的地方就是要改成画面/声音的地方。

### 用声音承载信息（省成本的高级手段）
```
　　广播声（画外）
　　　　　提醒各位用户，本月的记忆配额将于今晚二十四点清零。
```
可用：广播/通告音、电话、设备提示音、字幕数据、旁人窃窃私语。

### 结尾（最后一击）
```
　　他关掉工作台。屏幕暗下去的一瞬，反光里映出一行没来得及关的日志：

　　　　　　"代理：阿哲　　维护人：父亲　　起始日期：八年前"

　　　　　　　　　　　　　　　　　　　　　　　　　　　　　切黑
```
**规则**：
- 最后一击必须是**画面**能说清的，不能靠台词。
- 翻转完成后**立刻切黑**。不要多给 5 秒。
- 不给答案，给更大的问题。

## 四、交付前 10 条自检（与 SKILL.md 步骤 8 一致）

- [ ] 只有一个点子、一次反转
- [ ] 最后 10 秒的反转是画面能说清的
- [ ] 开场 10 秒内建立常态或抛出异常
- [ ] 没有任何地方在解释设定
- [ ] 推演严格，没有破坏自己立的规则
- [ ] 结尾给的是更大的问题
- [ ] 奇观低成本可执行；视觉母题出现三次并变义
- [ ] 时长与模板匹配
- [ ] 抽掉科幻构思，故事会塌
- [ ] 剥掉科幻外壳，情感内核仍立得住
