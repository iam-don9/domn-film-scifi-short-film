# 取材地图：从哪一类科幻里找短片素材

> **可选背景资料（agent 用）**。只有当用户明确要"改编某个已有的科幻小说"、或需要判断某类素材是否适合短片时，才查本文件。
> **不需要读任何作品也能走完主流程**——主流程的原料库已足够原创。

> 不是所有科幻都适合做短片。本文件回答：**哪一类作品、哪些篇目，适合改成什么规格的短片。**

---

## 一、中国科幻作家谱系 → 短片适配度

| 作家 | 风格 | 适合的短片规格 | 改编难度 | 备注 |
|---|---|---|---|---|
| **刘慈欣** | 冷峻、宏大、厚重；正统硬科幻；"不扯别的，就扯科技" | **C5（5–15 分钟）** | ⚠️ **高**。主人公常是"全人类"，人物类型化，结尾不闭合 | 最能出**惊奇感**，但最难落地。做短片要么用双线汇流，要么取其中一个侧面 |
| **王晋康** | 质朴平实、乡土气息；哲理味浓；科学伦理困境 | **8 拍（15–30 分钟）或 C5** | 🟡 **中**。伦理困境常能落到一个人身上 | **成本最低**——单一场景即可成立，最适合实拍与 AIGC |
| **何夕** | 细腻温情、人文关怀；四大天王中**感情戏最好**；短篇远胜长篇 | **C5 或 8 拍** | ✅ **低**。人物立得住，赌注是情感性的 | **短片改编最友好的取材区之一** |
| **韩松** | 诡谲、阴森、猎奇；"赛博聊斋＋克苏鲁" | **3 拍或 C5** | ✅ **低**。氛围即内容，天然适合短片 | 重气氛轻情节，正好匹配短片的"暗示而非展示" |
| **新生代**（陈楸帆、张冉、江波、宝树、夏笳、郝景芳等） | 近未来、社会科幻、技术问题个人化 | **C5（最推荐）** | ✅ **最低**。设定已落地，冲突在具体生活里 | **短片取材的首选区**。郝景芳《北京折叠》获 2016 雨果奖 |

**一句话选材策略**：
- 要**惊奇感** → 刘慈欣，用 C5，接受难度。
- 要**可落地、可拍、人物立得住** → 何夕 / 韩松 / 新生代，用 C5 或 8 拍。
- 要**最低成本、单一场景** → 王晋康式伦理困境。

## 二、建议篇目（按短片适配度分类）

### 最适合直接改短片
| 篇目 | 作者 | 为什么适合 | 建议规格 |
|---|---|---|---|
| 《带上她的眼睛》 | 刘慈欣 | 有具体人物、有情感赌注、有单一场景（地心舱）、结尾有翻转 | C5 / 8 拍 |
| 《朝闻道》 | 刘慈欣 | 单一设定（真理的代价）、单一场景（祭坛）、结尾即高潮 | C5 |
| 《坍缩》《微观尽头》 | 刘慈欣 | 极短，单一构思，纯概念型 | **3 拍**（AIGC 短视频首选） |
| 《乡村教师》 | 刘慈欣 | 双线汇流的教科书；小—大横比；意象收束 | **8 拍**（需两线，短片较难） |
| 《生命之歌》《地火》《十字》 | 王晋康 | 伦理困境，单一场景可成立，低成本 | C5 / 8 拍 |
| 《六道众生》《伤心者》《我是谁》 | 何夕 | 人物与情感扎实，人物驱动 | C5 / 8 拍 |
| 《地铁》 | 韩松 | 氛围驱动，暗示式，天然短片化 | 3 拍 / C5 |
| 《北京折叠》 | 郝景芳 | 设定已落地，冲突在具体生活里 | 8 拍 |

### 适合取"一个侧面"而非整体改编
- 《流浪地球》《三体》《赡养人类》等设定宏大的作品 → **不要整体改**。取其中一个**职业、一个场景、一条支线**（用"职业化"算子）。

### 国外可参照的短篇结构老师（拓展）
| 作家 | 为什么值得学 |
|---|---|
| **特德·姜（Ted Chiang）** | 短篇结构的最高范本。**几乎每篇都是"一个哲学命题 + 一次认知翻转"**。《你一生的故事》被改编为电影《降临》。学他的"**构思与故事的不可分割**" |
| **雷·布拉德伯里（Ray Bradbury）** | 极短篇（short short）的大师。学他如何用**一个意象**承担整篇 |
| **菲利普·K·迪克（Philip K. Dick）** | 大量短篇被改编成电影。学他的"**日常里渗出一个不对劲**"的切入方式 |
| **阿瑟·克拉克（Arthur C. Clarke）** | 刘慈欣的精神源头之一。学"**冷静语气写超现实**" |
| **刘宇昆（Ken Liu）** | 《手中纸，心中爱》为雨果/星云/世界奇幻三奖首例。学"**技术设定与私人情感的缝合**" |

## 三、取材时的三个提醒

1. **先做塌架测试再动笔**。抽掉科幻构思，故事还成立吗？成立 → 你选的其实是"有科幻背景的别的故事"，短片会失去存在的理由。
2. **警惕"设定宏大"的诱惑**。《三体》级的设定塞不进短片。**越大的设定，越要往小里取**——取一个从业者、一个流程、一天。
3. **改编不是搬运**。小说的结尾往往不能直接用（小说可以留白，短片必须给画面）。**先写"最后 5 秒"，再倒推。**
