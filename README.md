# domn-film-scifi-short-film

> 独立技能仓库 · 来自 domn skills 集合（视频制作 域）

科幻短片剧本写作执行流程。当用户提出科幻短片、科幻剧本、科幻短视频、AIGC 科幻、短片脚本需求，或给出模糊科幻创意要求"帮我想点子/这个设定能不能拍/脑洞"时使用。按 8 个步骤产出 logline、点子卡、逐拍结构表与可拍剧本，内含点子发生器（10 原料库×12 算子）、双向筛选测试、三种时长的拍子模板与剧本格式。仅适用 ≤30 分钟；超过 30 分钟改用 domn-film-screenplay-save-the-cat。
